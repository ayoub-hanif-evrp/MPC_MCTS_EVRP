# Retired Generated-Scenario Cache

Stale scenarios have been removed. Keep this directory empty except for this README.

and reuse them across algorithms. Record benchmark/reference hashes, generator
identity, target/realized DoD, and seeds; reject stale dependencies.

Benchmark files and existing reference schedules are separate inputs and must not
be deleted during generated-scenario cleanup.
