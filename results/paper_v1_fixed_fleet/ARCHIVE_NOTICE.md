# V1: Diagnostic Archive, Not Final Paper Results

V1 used the static reference fleet size as a hard online fleet cap. All executions
passed physical/information audits, but all paper runs were incomplete. These
results are diagnostic and are not the final paper campaign.

This is a byte-verified copy of the completed 704-condition campaign. Original
records, metadata, figure files and tables have not been rewritten. Relative
paths in the original index still reference the preserved `results/paper` and
calibration archive. V2 diagnostics are separate under `results/paper_v2`.
